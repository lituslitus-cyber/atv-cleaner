# Очистка Xiaomi TV

Портативная программа для Windows: убирает предустановленный мусор с
телевизоров и приставок Xiaomi (и других Android TV / Google TV) через ADB.
Устанавливать ничего не нужно, ADB уже внутри.

## Как пользоваться

1. Скачайте `XiaomiTVCleaner.exe` из раздела **Releases** и положите в любую
   папку: рядом с ним появятся бэкапы.
2. На телевизоре: Настройки → Об устройстве → 7 раз нажмите «Сборка». Затем
   в «Для разработчиков» включите «Отладку по USB» и «Отладку по сети».
3. Запустите программу, введите IP телевизора и нажмите **Подключить**.
   На ТВ разрешите отладку.
4. **Найти мусор** покажет кандидатов по группам. Отметьте ненужное
   и нажмите **Удалить отмеченное**.
5. Согласитесь на перезагрузку с проверкой: если ТВ не загрузится до главного
   экрана, удалённое вернётся само.

## Безопасность

- Удаление идёт через `pm uninstall -k --user 0`: системный APK остаётся
  в прошивке. Кнопка **Восстановить из бэкапа** или сброс к заводским
  настройкам всё возвращают.
- Программа не даёт удалить системные компоненты, голосовой поиск,
  последний лаунчер и последнюю клавиатуру, persistent-пакеты и
  пакеты с правами системы.
- Перед удалением сохраняется бэкап: список пакетов и APK сторонних
  приложений.

## Без exe

`Запустить очистку ТВ.bat` запускает консольную версию
(`xiaomi_tv_cleanup.py`), нужен только Python. Окно: `python gui.py`.
