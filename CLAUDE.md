# ATV Cleaner: правила работы

- `atv_cleaner.py` — вся работа с ТВ через ADB (используется и консолью, и окном),
  `gui.py` — окно на tkinter. Тексты интерфейса и комментарии на русском.
- Пользователь присылает правки по одной. Каждую записывать пунктом в раздел
  «Не выпущено» в `CHANGELOG.md`. Пушить в `main` можно: обычный пуш только
  проверяет, что exe собирается, релиз не создаётся.
- **Релиз делать только по прямой команде пользователя** («релизни» и т. п.):
  1. поднять `__version__` в `atv_cleaner.py`;
  2. переименовать «Не выпущено» в `## <версия> — <дата>` и добавить сверху
     новый пустой раздел «Не выпущено»;
  3. коммит с `[release]` в сообщении и пуш: сборка создаст релиз, текст
     релиза возьмётся из этого раздела.
- Эта сессия не может создавать теги и удалять релизы через API: релиз
  создаёт сама сборка на GitHub, старые релизы пользователь удаляет вручную.
- Перед удалением/отключением пакетов программа всегда проверяет влияние на
  загрузку. Новые пакеты в каталог добавлять только по проверенным
  источникам; неизвестные системные пакеты по умолчанию не трогать.
